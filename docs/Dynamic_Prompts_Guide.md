# Dynamic Prompts & コンテキスト制御ガイド

Project Wannabe では、本文や詳細情報の中に特定の記号を書くことで、**AIに送る内容だけ**を調整できます。

元のテキストは消えません。コメントアウトや範囲指定は、生成時にプロンプトを組み立てる直前の前処理として反映されます。

主な用途は次の3つです。

* 自分用メモを AI に読ませない
* 長くなった本文のうち、AI に読ませる範囲を指定する
* 生成ごとにランダムな言葉を差し替える

## 1. 使える場所

Dynamic Prompts とコンテキスト制御は、生成時に AI へ送られるテキストに対して使えます。

主な対象:

* 本文
* 次の展開の指示
* タイトル
* キーワード
* ジャンル
* あらすじ
* 設定
* プロット
* 思考 prefill
* 汎用モードの System Prompt

メモ欄にも見た目上の強調表示は入りますが、メモはそのままでは生成プロンプトに含まれません。メモの内容を AI に読ませたい場合は、本文や詳細情報へ移してください。

## 2. コメントアウト機能

コメントアウトは、**テキストを残したまま AI には読ませたくない**ときに使います。

推敲メモ、没案、作者用メモ、あとで書き直したい箇所などに向いています。

### 行末コメント: `@//`

`@//` から行末までを AI に送らないようにします。

使用例:

```text
吾輩は猫である。 @// ここはあとで書き直す
名前はまだない。
```

AIに送られる内容:

```text
吾輩は猫である。 
名前はまだない。
```

行の途中から使えるため、本文を残しつつ短いメモを付けたいときに便利です。

### 範囲コメント: `@/* ... @*/`

`@/*` から `@*/` までをまとめて AI に送らないようにします。

複数行をまとめて隠したいときに使います。

使用例:

```text
昔々、あるところに
@/*
（ここからボツ案）
おじいさんとおばあさんがいました。
（ここまでボツ案）
@*/
勇敢な女騎士がいました。
```

AIに送られる内容:

```text
昔々、あるところに

勇敢な女騎士がいました。
```

範囲コメントの終了記号は `@*/` です。`*/@` ではありません。

## 3. コンテキスト範囲の制御

本文が長くなると、AI に読ませたい範囲を明示したくなることがあります。

Project Wannabe には、本文の一部だけをプロンプトに含めるためのタグがあります。

### 開始地点を指定する: `@break` / `@startpoint`

`@break` または `@startpoint` より上の文章を AI に送らないようにします。

複数ある場合は、**一番下にあるもの**が有効です。

使用例:

```text
第一章の長い本文。
主人公は王都を追放された。

@break

第二章
主人公は雨の森で目を覚ました。
```

AIに送られる内容:

```text

第二章
主人公は雨の森で目を覚ました。
```

便利な場面:

* 章が変わったので、古い文脈を切りたい
* 途中から別ルートの展開を試したい
* 冒頭の古い設定に引っ張られたくない
* 長い本文のうち、直近だけを強く読ませたい

`@break` と `@startpoint` は同じ目的で使えます。好みで使い分けてください。

### 終了地点を指定する: `@endpoint`

`@endpoint` より下の文章を AI に送らないようにします。

複数ある場合は、**有効範囲内で一番上にあるもの**が使われます。

使用例:

```text
彼は剣を抜いた。
@endpoint

ここから先は、まだAIに読ませたくない未来の展開。
魔王は倒れ、王国は救われた。
```

AIに送られる内容:

```text
彼は剣を抜いた。
```

便利な場面:

* すでに書いた後半を隠して、途中のシーンを挿入したい
* 未来の展開を AI に見せずに、手前の描写だけ生成したい
* 後半を書き換える前に、前半だけをもとに候補を出したい

### `@break` と `@endpoint` を組み合わせる

`@break` と `@endpoint` を組み合わせると、本文の中間だけを AI に送れます。

```text
第一章
王都での出来事。

@break

第二章
森で迷う主人公。
ここを詳しく書きたい。

@endpoint

第三章
村に到着したあとの展開。
```

AIに送られる内容:

```text

第二章
森で迷う主人公。
ここを詳しく書きたい。
```

挿入執筆や分岐展開を試すときに便利です。

## 4. Dynamic Prompts（ランダム選択）

`{}` の中に `|` で区切った候補を書くと、生成時にその中からランダムに1つが選ばれます。

基本形:

```text
{選択肢A|選択肢B|選択肢C}
```

使用例:

```text
空からは{雨|雪|灰}が降っていた。
```

AIに送られる内容の例:

```text
空からは雪が降っていた。
```

次に生成したときは、別の候補になる場合があります。

### スペースを含む選択肢

スペースを含む候補は、引用符で囲めます。

```text
彼女は{"古い剣"|"銀の短剣"|"魔法の杖"}を手に取った。
```

AIに送られる内容の例:

```text
彼女は銀の短剣を手に取った。
```

シングルクォートも使えます。

```text
街には{'白い塔'|'黒い城壁'|'赤い橋'}があった。
```

### キーワードやジャンルで使う

キーワードやジャンルのタグ内でも使えます。

例:

```text
{追放|復讐|成り上がり}
```

生成のたびに、AI に渡るキーワードが変わります。

### 使いどころ

Dynamic Prompts は、次のような試行錯誤に向いています。

* 天候や時間帯を少し変えたい
* 登場する小物をランダムにしたい
* 感情の方向性を候補から選ばせたい
* アイデア出しで複数のジャンルを試したい
* 同じプロットから少し違う雰囲気の候補を出したい

## 5. 処理の順番

生成時には、次の順番で処理されます。

1. コメントアウトを除去する
2. `@break` / `@startpoint` / `@endpoint` で範囲を切り出す
3. `{A|B|C}` をランダムに展開する
4. Project Wannabe がプロンプトを組み立てる
5. KoboldCpp に送信する

このため、コメントアウトされた範囲に `@break` や `{A|B}` があっても、それらは無視されます。

例:

```text
ここはAIに読ませる。
@// {雨|雪} はコメント内なので使われない
ここもAIに読ませる。
```

AIに送られる内容:

```text
ここはAIに読ませる。

ここもAIに読ませる。
```

## 6. 注意点

### ネストは非対応

次のような入れ子は正しく扱えません。

```text
{A|{B|C}}
```

候補を入れ子にしたい場合は、展開後の形をそのまま候補にしてください。

```text
{A|B|C}
```

### `{}` を普通の文字として使いたい場合

現在、`{A|B}` のように `|` を含む `{}` は Dynamic Prompts として扱われます。

本文中で波括弧をそのまま使いたい場合は、`|` を入れない、または別の記号に置き換えるのが安全です。

### コメントタグも本文からは消える

`@//` や `@/* ... @*/` は、AI に送る内容から削除されます。削除後の改行や空白の残り方によって、AI が見る文章のつながりが少し変わる場合があります。

### `@break` は本文を消すわけではない

`@break` より上の文章は、プロジェクトファイルや本文エリアから消えるわけではありません。あくまで生成時に AI へ送られないだけです。

## 7. 実用例

### 作者用メモを残しながら生成する

```text
彼女は塔の扉に手をかけた。 @// ここで鍵の伏線を出すか検討
扉の向こうから、かすかな歌声が聞こえた。
```

AIには、メモを除いた本文だけが送られます。

### 途中から続きを書かせる

```text
第一章の本文が長く続く。
...

@break

第二章
雨の街で、主人公はかつての仲間と再会した。
```

AI は第二章以降だけを見て続きを考えます。

### 未来の展開を隠して挿入シーンを書く

```text
主人公は地下室へ降りた。
@endpoint

後で書いた展開:
地下室で真犯人を見つける。
```

AI は後半を見ないため、未来の展開に引っ張られずに地下室へ降りる場面を生成できます。

### 生成ごとに雰囲気を変える

```text
次の展開の指示:
主人公は森で{迷子のドラゴン|傷ついた騎士|古い魔導書}を見つける。
雰囲気は{静か|不穏|幻想的}にする。
```

同じ本文から、少しずつ違う候補を出したいときに使えます。
